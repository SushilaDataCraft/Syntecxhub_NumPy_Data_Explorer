# NumPy Data Explorer

## Project Overview
NumPy Data Explorer is a Python project developed as part of the **Syntecxhub Data Science Virtual Internship**. It demonstrates essential NumPy operations for working with numerical data efficiently.

## Features
- Create NumPy arrays and perform indexing and slicing.
- Perform mathematical and statistical operations.
- Calculate values along different axes.
- Reshape arrays and use broadcasting.
- Save and load NumPy arrays.
- Compare the performance of Python lists and NumPy arrays.
- Filter array elements based on conditions.

## Technologies Used
- Python
- NumPy
- Visual Studio Code (VS Code)

## Installation
Install NumPy using the following command:

```bash
python -m pip install numpy
```

## How to Run
1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Run the following command in the terminal:

```bash
python numpy_data_explorer.py
```

## Project Purpose
The purpose of this project is to gain practical experience with NumPy arrays, numerical computations, data manipulation, and performance optimization in Python.
